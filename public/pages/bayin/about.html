关于八音

项目简介

八音（BaYin）是一款面向桌面与移动端的现代化音乐播放器，基于 Tauri 2 + React + Rust 原生音频引擎 构建，兼顾颜值、性能与跨平台一致性。

它不仅支持本地音乐库管理，也支持接入多种流媒体服务器（Navidrome、Jellyfin、Emby、Subsonic），并提供歌词、均衡器、频谱可视化、系统媒体控制、托盘等完整播放器能力。

技术栈

核心框架

  • • Tauri 2 - 桌面应用框架
  • • React 18 - 前端框架
  • • TypeScript - 类型安全
  • • Vite - 构建工具

UI & 样式

  • • Tailwind CSS 4 - 样式框架
  • • Radix UI - 组件库
  • • Framer Motion - 动画

音频引擎 (Rust)

  • • symphonia - 音频解码
  • • cpal - 跨平台音频播放
  • • rustfft - 频谱分析
  • • rubato - 重采样

状态 & 路由

  • • React Context - 状态管理
  • • React Router - 路由
