常见问题

以下是一些常见问题的解答。如果你的问题没有在这里找到答案，欢迎在 GitHub Issues 或 TG 群组 中提问。

八音支持哪些音频格式？

八音支持以下音频格式：MP3、FLAC、WAV、AAC、M4A、OGG、AIFF、OPUS。基于 Rust 的 symphonia 解码库，提供高质量的音频播放体验。

如何连接流媒体服务器？

八音支持多种流媒体服务器协议：

  • • Navidrome：在设置中输入服务器地址和凭证
  • • Jellyfin：输入服务器 URL 和 API Key
  • • Subsonic：支持所有 OpenSubsonic 兼容的服务器

八音支持哪些平台？

目前支持 Windows（10/11）、macOS（10.15+） 和 Linux。移动端（Android、iOS）版本正在开发中。

如何导入本地音乐库？

在设置中点击「添加文件夹」，选择你的音乐文件夹。八音会自动扫描并导入音乐文件，同时监听文件夹变动，自动同步新增或删除的音乐。

歌词文件放在哪里？

将 .lrc 歌词文件与音乐文件放在同一目录下，文件名保持一致即可。例如：song.mp3 和 song.lrc

均衡器如何使用？

在播放界面点击均衡器按钮，可以选择预设或自定义 10 段均衡器参数。支持多种音效预设（流行、摇滚、古典、爵士等）。

如何切换主题？

在设置中可以切换深色/浅色主题，或选择跟随系统主题。八音采用 macOS 风格设计，提供优雅的视觉体验。

八音是开源的吗？

是的！八音基于 Apache License 2.0 开源。你可以在 GitHub 上查看源代码、提交 Issue 或贡献代码。
