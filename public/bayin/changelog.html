v2.3.9

2026-06-04

🚀 新功能

首页推荐引擎（全新上线）

  • • 新增智能首页推荐系统，包含 6 大个性化模块
  • • 每日推荐电台（Daily Mix）：基于播放次数、最近播放、音质加权随机推荐
  • • 最近播放、最新添加、发现音乐、推荐艺术家、遗忘的收藏
  • • 新增独立首页开关，可选择启动显示首页或歌曲列表
  • • 首页卡片全新设计：模糊封面背景、横向滚动、远程封面支持

播放统计与历史

  • • 新增播放统计追踪：数据库升级 v8，增加 play_count / last_played_at
  • • 自动记录每首歌播放次数与最后播放时间
  • • 新增最近播放页面，支持多维度排序
  • • 歌曲列表显示播放次数

流媒体推荐优化

  • • 推荐算法全面支持远程流媒体库（Subsonic/Navidrome/Jellyfin）
  • • 艺术家卡片显示远程封面
  • • 每日推荐修复 ID 错误，改用 RANDOM() 随机算法

Pro 功能 IAP 架构搭建

  • • 新增应用内购买（IAP）基础流程
  • • 新增《会员服务协议》页面
  • • 全平台 IAP 抽象层，后续接入插件无需改动业务代码

🐛 Bug 修复

  • • 修复每日推荐列不存在错误
  • • 修复新歌推荐无数据时空白问题
  • • 优化顶级艺术家查询，支持远程封面显示
  • • 修复首页路由滚动锁定问题
